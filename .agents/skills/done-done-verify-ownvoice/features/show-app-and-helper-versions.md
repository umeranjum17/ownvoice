# Show app and helper versions

Target: Ownvoice Android app, Home and About.

Drive a fresh stub-build install on a task-owned emulator. At the writer choice, choose **Not now** so setup ends without connecting an account. On Home, scroll to the bottom and check the app version and pre-release marker. Open About with the app's own `ownvoice://about` route and check its app version, build number, and release status. If testing a paired helper, pair it through Home → **Use my computer** first; About should show the helper's reported version and explain when the two versions differ.

Capture Home and About at 360, 390 and 445 dp in light and dark, with 1.3 system font scale; add 1280×800 light/dark captures when the app is tested in a large-screen window. Check the real screenshots for readable text, clipping, overlap and a visible pre-release label. The app version comes from the installed build, not from a typed-in expected label.
