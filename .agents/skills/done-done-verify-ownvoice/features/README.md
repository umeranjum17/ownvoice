# ownvoice features

The repo's maintained verification map; a proof that drives one entry point is incomplete when this lists others.

- [Check drafts against never-say rules](check-drafts-against-never-say-rules.md): A caller (an agent or script) sends one check request to the engine, the same way the mobile writer does before it shows a draft
- [Parse a writing-voice note into rules](parse-a-writing-voice-note-into-rules.md): A user saves Your voice (the never-say list and the How-I-write note) in the app. The app sends the same markdown to the engine's voice.parse verb
- [Get the platform list and per-platform limits](get-the-platform-list-and-per-platform-l.md): A caller asks which platforms the engine knows before it drafts for one of them
- [Read the published protocol schema](read-the-published-protocol-schema.md): A caller wants the request and response shapes before it sends anything
- [Reject bad requests with a readable error](reject-bad-requests-with-a-readable-erro.md): A caller sends a malformed or unknown request by mistake
